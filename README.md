# Проект «Посмотри в окно»

Учебный проект, выполненный в рамках курса «Веб-разработчик» от Яндекс Практикума. 
Интерактивная страница, которая позволяет просматривать видеоролики из разных городов в разное время суток. 

## Функциональность

- **Динамическая загрузка данных**: Карточки с видео подгружаются с внешнего API.
- **Переключение видео**: При клике на карточку в правой колонке, видео в основном плеере меняется, а карточка получает фоновую подсветку (текущая карточка).
- **Поиск и фильтрация**: Форма позволяет искать видео по названию города (с учетом регистра и раскладки) и фильтровать по времени суток (Утро, День, Ночь).
- **Пагинация**: Кнопка «Показать ещё» подгружает новые карточки.
- **Состояния загрузки и ошибок**: При загрузке данных отображаются кастомные прелоадеры, а при ошибке сети или отсутствии результатов — заглушки с сообщениями.
- **Доступность (A11y)**: Поддержка навигации с клавиатуры (видимый фокус), кастомные стилизованные чекбоксы, скрытые лейблы для скринридеров.

## Стек технологий

- **HTML5**: Семантическая разметка, использование тегов `<template>` для динамической генерации контента.
- **CSS3**: 
  - Flexbox для построения сетки и выравнивания элементов.
  - Кастомные свойства (CSS-переменные) для цветов.
  - Псевдоклассы (`:hover`, `:active`, `:focus-visible`, `:has`) и псевдоэлементы (`::after`).
  - `object-fit` для корректного отображения видео и изображений.
  - Кастомный скроллбар (`::-webkit-scrollbar`).
- **JavaScript (ES6+)**: 
  - Асинхронные запросы к API (`fetch`, `async/await`).
  - Работа с DOM (клонирование шаблонов, добавление/удаление классов, прослушивание событий).
  - Обработка ошибок (`try...catch`).
